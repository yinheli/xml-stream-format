browser demo

Drop an XML file of any size.

It is parsed in a Web Worker by the same library code that powers the CLI: strict decoding, Expat compiled to WASM and the same ingest pipeline. Reading is demand-driven, so only what fills the screen gets parsed. Nothing leaves your machine.

  • first screen before EOF, even for multi-GB files
  • folding, keyboard & mouse navigation like the terminal browser
  • fuzzy name search, XPath 3.1, statistics
  • copy paths or formatted subtrees · export the whole file, formatted
